## Цель проекта

Создать текстовую (одиночную) игру с небольшим заданным миром, персонажами, предметами и их состояниями. LLM выступает рассказчиком и ведущим: интерпретирует действия игрока, выбирает действия NPC и описывает последствия. Взаимодействие с состоянием игрового мира будет реализовано через function calling.

Исследовательская часть проекта — оценить, как небольшие LLM справляются с управлением заданным миром, и проверить, как дообучение и способы организации контекста и фоновых событий влияют на корректность действий и связность повествования.

## Идея игры

В начале игры задаются локации, персонажи, предметы, их свойства и допустимые изменения состояний. У NPC могут быть собственные цели и отношения с другими персонажами. Игрок описывает действия на естественном языке: исследует локации, общается с NPC, выполняет задания и использует предметы. Развитие истории складывается из последствий его решений и событий внутри мира.

Предварительное направление — фэнтезийные приключения и задания гильдии. Для первой версии планируется небольшой мир с ограниченным числом персонажей и локаций. Конкретные механики и сценарии будут уточняться после анализа данных и первых экспериментов с моделями.

#### Фоновые события

NPC могут действовать для достижения собственных целей, в том числе вне текущей сцены игрока. Планируется исследовать развитие мира при продвижении игрового времени, включая сценарии без вмешательства игрока. Для прототипа такие события можно обрабатывать по игровым шагам; частота обновлений и способ выбора действий NPC будут определены экспериментально.

#### Function calling

Модель получает нужную часть состояния мира и сообщение игрока либо описание наступившего игрового события, выбирает функции и их аргументы. Игровая логика проверяет допустимость действия, выполняет его и сохраняет изменения. Затем модель использует результат для продолжения сцены
